==================================================
 🎵 دليل التشغيل المحلي لبوت ديسكورد (Local Bot Guide)
==================================================

أهلاً بك! لتشغيل البوت على جهازك الشخصي بشكل صحيح ومستقر، اتبع الخطوات التالية بالترتيب:

--------------------------------------------------
 1️⃣ الخطوة الأولى: تثبيت Node.js
--------------------------------------------------
* يجب تحميل وتثبيت Node.js من الموقع الرسمي حصراً لتجنب أي مشاكل:
  🔗 https://nodejs.org/
* أو إذا كنت تستخدم نظام Windows 11، يمكنك فتحه عبر سطر الأوامر (PowerShell / Terminal) بصلاحيات المسؤول وتثبيته مباشرة بهذا الأمر:
  `winget install OpenJS.NodeJS`

--------------------------------------------------
 2️⃣ الخطوة الثانية: تثبيت وتجهيز محرك الصوت FFmpeg
--------------------------------------------------
* يحتاج البوت إلى محرك FFmpeg لتحويل وتشغيل الملفات الصوتية بصيغة (MP3) في ديسكورد.
* قم بتحميله من الموقع الرسمي:
  🔗 https://www.ffmpeg.org/
* (ملاحظة: لِمستخدمي Windows 11 قد لا تجده في المتجر الرسمي لأنه أداة مفتوحة المصدر تم تطويرها بواسطة مجتمع المبرمجين).

📌 **طريقة إضافة مسار FFmpeg لمتغيرات النظام (Environment Variables):**
1. قم بفك الضغط وضع مجلد FFmpeg في القرص المحلي مباشرة ليصبح مساره هكذا:
   `C:\bin\ffmpeg` (أو المجلد الذي يحتوي على مجلد الـ bin بداخله).
2. افتح بحث ويندوز واكتب: **متغيرات البيئة** أو (Edit the system environment variables).
3. أضف مسار مجلد الـ bin الخاص بـ FFmpeg إلى متغيرات النظام (Path) ليعمل معك البوت بدون مشاكل.

--------------------------------------------------
 3️⃣ الخطوة الثالثة: إعداد التوكن والتشغيل
--------------------------------------------------
1. افتح ملف المشروع الأساسي `index.js` باستخدام أي محرر أكواد (مثل VS Code).
2. ابحث عن السطر الخاص بالتوكن باستخدام (`Ctrl + F`):
   `const TOKEN = "";`
3. ضع **التوكن (Token)** الخاص ببوتك بين علامتي التنصيص.
4. توجه إلى مجلد المشروع عبر سطر الأوامر (Terminal) واكتب الأوامر التالية بالترتيب:
   * لتثبيت التبعيات والمكتبات المطلوبة:
     `npm install`
   * لتشغيل البوت:
     `npm start` (أو يمكنك استخدام `node index.js`)

🎉 **الخطوة الأخيرة:** توجه إلى سيرفر ديسكورد، استخدم الأمر المخصص للوحة التحكم، واستمتع بالبوت!
