# 🎵 Local Music Discord Bot

بوت ديسكورد مبني بـ **Node.js**، مخصص لتشغيل الأغاني والملفات الصوتية مباشرة من مجلد محلي داخل ملفات البوت، مع لوحة تحكم متكاملة وسهلة الاستخدام.

---

## ✨ المميزات
* **تشغيل محلي:** تشغيل الملفات الصوتية بسلاسة من مجلد `songs/` المخصص داخل البوت.
* **لوحة تحكم (Dashboard):** واجهة تحكم مرنة لإدارة البوت بكل سهولة.
* **خفيف ومستقر:** مبني بأحدث تقنيات Node.js ليستهلك أقل قدر من الموارد.

## 🛠️ طريقة التثبيت والتشغيل محلياً

1. **استنساخ المستودع (Clone):**
   ```bash

   cd bot_voic
تثبيت الحزم والمكتبات المطلوبة:

Bash
npm install
إعداد ملف البيئة أو التوكن:

تشغيل البوت:

Bash
